# 영단어 암기 도우미 V3.2 · 관리자 기능

## 실행

1. Node.js 18 이상을 설치합니다.
2. 이 폴더의 `server.js`, `index.html`, `style.css`, `script.js`, `package.json`을 같은 폴더에 둡니다.
3. **기존 단어 JSON을 같은 위치의 `vocab.json`으로 둡니다.** `vocab.template.json`은 빈 템플릿 예시이므로 실제 단어 자료가 있다면 덮어쓰지 마세요.
4. 터미널에서 이 폴더로 이동해 실행합니다.

```bash
npm start
```

또는 Windows에서 `start_windows.bat`를 실행할 수 있습니다.

```bash
node server.js
```

브라우저에서 `http://localhost:3000`을 엽니다. HTML 파일을 더블 클릭해 `file://` 주소로 열면 API가 작동하지 않으므로 반드시 서버 주소로 접속해야 합니다.

## 데이터 파일

- `vocab.json`: 사용자 단어 자료. 최상위 키는 문자열 `"1"`부터 `"13"`까지이며, 각 값은 항목 객체 배열입니다.
- `rankings.json`: 첫 실행 때 자동 생성됩니다. 이름, 점수, 총 풀이 시간, 각 문항의 문제·답안·정오·풀이 시간을 보관합니다.

`vocab.json`은 5초마다 변경 여부를 확인합니다. 학습 중 파일이 바뀌면 현재 문제는 유지하고, 홈으로 돌아갔을 때 최신 자료를 적용합니다.

앱을 업데이트할 때 `rankings.json`을 보존하면 기존 랭킹이 유지됩니다. 단어 자료도 배포 파일의 빈 템플릿으로 덮어쓰지 마세요.

## 점수 및 랭킹 규칙

- 퀴즈 전환 시 시작 안내 창에서 문항 수, 유형, 랭킹 등록 가능 여부를 확인합니다. 시작하기를 누르면 3·2·1 카운트다운 뒤 퀴즈가 시작됩니다.
- 문제마다 제한 시간은 10초입니다. 시간 초과는 오답입니다. 답안을 제출한 뒤 입력창에 포커스가 유지되므로 Enter로 다음 문제로 이동할 수 있습니다.
- 정답 점수는 문항당 1점입니다.
- 정답인 문항에 대해서만 남은 초를 시간 추가 점수로 더합니다.
- 최종 점수 = 정답 수 + 정답 문항의 남은 시간 합계(소수점 첫째 자리). 점수 합산 시 두 점수 카드가 중앙으로 이동하며 투명도가 낮아져 최종 점수와 겹치지 않습니다.
- 퀴즈 개수는 `10개`, `25개`, `50개`, `100개`, `200개`, `전부` 중에서 선택할 수 있습니다. 랭킹 등록은 `랜덤` 모드에서 `25개`, `50개`, `100개`, `200개`, `전부` 범위로 가능합니다. 25·50·100·200개 랭킹은 해당 수만큼 단어가 있는 경우에만 등록할 수 있습니다.
- 랭킹은 점수 내림차순으로 정렬합니다. 동점자는 같은 순위로 표시합니다. 상위 10위 안에 등록되면 축하 효과가 표시됩니다. 랭킹 및 결과 표는 헤더가 불투명한 배경으로 고정되며 표 영역 내부를 스크롤할 수 있습니다.
- 랭킹 상세에는 각 문제의 제시 내용, 표제어, 사용자 답안, 서버에서 다시 판정한 정오, 풀이 시간이 표시됩니다.

정답 비교는 유사도 채점이 아니라 정규화 후 완전 일치입니다. 괄호와 괄호 안의 내용은 제거하고, 공백 차이를 무시하며, 물결표와 하이픈 계열 문자를 동일하게 처리합니다. 뜻 항목 안에서 `/`, `,`, `，`로 구분된 표현은 각각 별도의 정답 후보로 인정하므로, 구분자 전후에 공백이 있어도 어느 한 표현만 입력하면 정답입니다.

## 관리자 기능 및 보안

서버를 실행한 뒤 `http://localhost:3000/admin.html`을 열어 관리자를 최초 설정합니다. **최초 설정은 서버 컴퓨터의 localhost에서만 허용됩니다.** 관리자 비밀번호는 12자 이상이어야 하며, 16자 이상의 긴 문구를 권장합니다. 비밀번호는 평문으로 저장하지 않고, 랜덤 salt를 사용한 scrypt 해시로 `admin-auth.json`에 저장됩니다. 이 파일, `rankings.json`, 관리자 작업 로그 및 서버 코드 파일은 정적 파일 경로에서 제공하지 않습니다.

관리자 페이지에서는 랭킹 이름·점수·문항별 입력 답안·정오·풀이 시간을 편집하거나 기록을 삭제할 수 있습니다. 현재 점수 공식으로 만점 기록도 생성할 수 있습니다. 단어 항목은 추가·수정·삭제 가능하며, 변경 사항은 `vocab.json`에 저장됩니다. 관리자 작업의 시간과 유형은 `admin-audit.jsonl`에 기록됩니다. 관리자 세션은 HttpOnly/SameSite 쿠키와 서버 측 만료 시간으로 관리하고, 변경 요청에는 CSRF 토큰과 출처 검사를 적용합니다. 로그인 시도는 IP 기준으로 제한됩니다.

기본 서버 바인딩은 `127.0.0.1`이므로 같은 컴퓨터에서만 접속할 수 있습니다. LAN의 다른 기기에서 사용하려면 `HOST=0.0.0.0`을 명시적으로 설정해야 합니다. **인터넷에 공개할 경우 반드시 HTTPS 역방향 프록시 뒤에서 운영하고, `TRUST_PROXY=1`은 신뢰할 수 있는 프록시가 있을 때만 설정하세요.** 일반 HTTP로 외부에 직접 공개하는 것은 권장하지 않습니다. 관리자 보호와 별개로 일반 사용자 랭킹 등록 API는 공개되어 있으므로, 이 앱은 경쟁 부정 행위를 완전히 방지하는 온라인 시험 플랫폼은 아닙니다. 서버가 받은 풀이 시간은 클라이언트가 제출한 값이므로 공정성 보장이 중요하면 서버 측 퀴즈 세션과 타이머 검증이 추가로 필요합니다.

### 보존할 파일

업데이트할 때 기존 `vocab.json`과 `rankings.json`은 덮어쓰지 마세요. 이미 관리자 계정을 설정한 경우 `admin-auth.json`도 보존해야 로그인할 수 있고, `admin-audit.jsonl`을 보존하면 관리 기록도 유지됩니다. ZIP에는 이 데이터 파일들을 넣지 않습니다.
