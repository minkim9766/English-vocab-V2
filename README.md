# 영단어 암기 도우미

로컬의 `영단어.csv` 파일을 이용해 플래시카드와 퀴즈를 제공하는 간단한 웹 앱입니다.

사용법:

1. 이 폴더 (`영단어`)에서 로컬 서버를 실행합니다. (브라우저는 로컬 파일을 직접 fetch할 수 없습니다.)

Windows에 Python이 있다면:

```powershell
python -m http.server 8000
```

2. 브라우저에서 http://localhost:8000 를 열고 `index.html`을 확인하세요.

3. 모드 선택 후 `플래시카드 시작` 또는 `퀴즈 시작`을 누릅니다.

메모:
- CSV는 첫 번째 열이 영어, 두 번째 열이 한국어로 가정합니다.
- 퀴즈에서 정답은 엄격하지 않으며, 철자 오타나 동의어 정도는 허용됩니다.
